# Music Diary - Фронтенд

## Как запустить проект:

1. Убедитесь, что у вас установлен Node.js.
2. Скачайте папку с проектом.
3. Откройте терминал в папке проекта и запустите локальный сервер с данными:
   `npx json-server db.json --port 3001`
4. Откройте файл `index.html` с помощью расширения Live Server (или просто в браузере, если сервер уже запущен).
5. Сайт доступен по адресу `http://127.0.0.1:5500`.

## Что уже реализовано:
- Верстка главной страницы и формы (по макету).
- Модальное окно добавления рецензии.
- Валидация полей (подсветка ошибок).
- Добавление карточки без перезагрузки страницы.
- Поиск и сортировка (на клиенте).
